# open-box

This project aims to create an open-source box for testing pollutants with various air quality sensors.

The box will be abailable as an STL file with a BOM for all else needed.

This repository will be updated over time.

## Implementation Ideas

Given that the housing material will have an effect on the levels of air quality detected, we will test various housing materials, including: 
 - 3d-printed (PLA, PETG, TPU)

 - Wood (Pine); 
 
 - Glass; 
 
 - Acrylic of varying thicknesses.
 
 - Drywall
